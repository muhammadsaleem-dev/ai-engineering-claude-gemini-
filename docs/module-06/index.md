# Module 06: Claude Code & Computer Use

This module examines Anthropic's developer CLI tool and the Computer Use API for desktop automation.

### Topics & Lessons
1. **Claude Code**:
   - Understanding Anthropic's agentic CLI tool for code generation, debugging, and refactoring.
   - Command-line workflows and context awareness.
2. **Computer Use API**:
   - The OS World automation paradigm.
   - Screenshot loop: Taking screenshots -> model coordinates -> executing mouse clicks/keyboard strokes.
   - Limitations, security boundaries, and human-in-the-loop design.
