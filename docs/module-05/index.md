# Module 05: Retrieval-Augmented Generation (RAG)

This module covers building knowledge retrieval pipelines that dynamically inject external company data into prompts.

### Topics & Lessons
1. **Document Ingestion & Chunking**: Splitting text effectively (fixed-size, recursive, semantic).
2. **Text Embeddings**: Converting text chunks into high-dimensional vectors.
3. **Vector Storage & Indexing**: Storing and querying vector representations.
4. **Similarity Retrieval**: Cosine similarity, Top-K retrieval, and re-ranking.
5. **Context Augmentation**: Formulating prompts containing retrieved chunks to ground answers and reduce hallucinations.
